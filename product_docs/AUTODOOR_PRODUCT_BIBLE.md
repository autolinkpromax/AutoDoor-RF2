## 🌟 1. บทนำและวิสัยทัศน์ผลิตภัณฑ์ (The Origin & Vision)

### ความเจ็บปวดของประตูรั้วรีโมทในยุคปัจจุบัน (The Modern Gate Dilemma)
บ้านในยุคปัจจุบันเกือบทุกหลังมี **ประตูรั้วรีโมทอัตโนมัติ** แต่ความจริงที่ผู้ใช้งานทุกคนต้องเผชิญในชีวิตประจำวันคือ:
1. **กลับถึงบ้านตอนฝนตกหนัก:** ต้องควานหารีโมทในเก๊ะคอนโซล หรือต้องหยิบมือถือมาปลดล็อก เปิดแอป แล้วรอหมุนโหลด 10–15 วินาที เพื่อจะกดปุ่มเปิดประตู
2. **รถพัสดุ / ไรเดอร์ส่งอาหารมาส่งของ:** พอกดเปิดประตูให้รถส่งของเข้ามา รถขับผ่านเซ็นเซอร์กันหนีบ ประตู **ปิดตามหลังใส่รถส่งของทันที** เพราะระบบแยกไม่ออกระหว่าง "เปิดให้ตัวเองเข้าบ้าน" กับ "เปิดค้างไว้ให้พัสดุลงของ"
3. **ความเสียหายของเกียร์มอเตอร์:** เวลากดสลับเปิด-ปิดเร็วๆ มอเตอร์กระชากกลับทิศทางทันทีจนเฟืองพลาสติกรูด มอเตอร์ไหม้ ค่าซ่อมหลักพันถึงหลักหมื่น
4. **ระบบ Smart Home ทั่วไปที่พึ่งพาเน็ตบ้าน 100%:** ถ้าวันไหนเราเตอร์ Wi-Fi แฮงก์ หรือเน็ตบ้านล่ม ประตูเปิดไม่ได้ กลายเป็นของไร้ประโยชน์ทันที

### วิสัยทัศน์ของ AutoDoor-RF2 (The Breakthrough)
**AutoDoor-RF2** ถูกออกแบบและสร้างขึ้นโดยทีมวิศวกรและเมคเกอร์ เพื่อสร้าง **"ประสบการณ์การเข้าบ้านที่ไร้รอยต่ออย่างแท้จริง (Zero-Friction Living)"** 
ไม่ใช่แค่การติดกล่องสวิตช์ Wi-Fi ธรรมดา แต่คือการผสาน **3 เทคโนโลยีไร้สาย** เข้าด้วยกันบนสถาปัตยกรรมระดับอุตสาหกรรม:
* **ESP-NOW (2.4GHz Ultra-low Latency Direct Mesh):** ตรวจจับรถยนต์ระดับมิลลิวินาที ไม่ต้องพึ่งพาเราเตอร์ Wi-Fi ขับเข้าใกล้เปิดเอง มีเสียงตอบรับ 2 ทางในห้องโดยสาร
* **RF 433MHz Dynamic Role Decoding:** ถอดรหัสคลื่นวิทยุระยะไกล พร้อมระบบแยกหน้าที่ปุ่ม 4 บทบาท (Auto / เปิดค้างส่งของ / ปิดทันที / หยุดฉุกเฉิน)
* **Standalone Web Dashboard + Dual OTA:** มีระบบเว็บเซิร์ฟเวอร์ในตัวเอง ปรับจูนระยะบนมือถือได้โดยตรง และอัปเดตระบบแบบไร้สายได้อย่างปลอดภัย

| :--- | :--- | :--- |

| **4. ความปลอดภัยต่อเกียร์มอเตอร์** | **Directional Reversal Deadband 2.4 วินาที** (สั่ง STOP 1.2s + พักเกียร์ 1.2s ก่อนกลับทิศ) | มอเตอร์กระชากกลับทิศทางทันที เฟืองรูดง่าย | สั่งตัด-ต่อตรง มอเตอร์กระชาก |
| **5. การทำงานเมื่อเน็ตบ้านล่ม** | **ทำงานได้สมบูรณ์แบบ 100%** (ESP-NOW และ RF เป็นคลื่นสื่อสารตรง) | ทำงานได้เฉพาะรีโมทเดิม | **ใช้งานไม่ได้เลย (Offline)** |
| **6. การดูแลรักษาและอัปเดตระบบ** | **Dual-Partition Web OTA ไร้สาย** อัปเกรดความสามารถใหม่ได้ตลอดชีพ | ทำไม่ได้ (ระบบตายตัว) | ต้องรออัปเดตจาก Cloud ต่างประเทศ |

## 🚗 3. เจาะลึกฟีเจอร์สำหรับผู้ใช้งาน (End-User Experience)

### 3.1 ประสบการณ์ "ขับถึงบ้าน ประตูเปิดต้อนรับเอง" (Hands-Free Arrival)
* **ESP-NOW Smart Vehicle Beacon:** ตัวแท็กขนาดกะทัดรัด เสียบช่อง USB หรือที่จุดบุหรี่ในรถยนต์
* **ระยะทำการที่แม่นยำ:** เมื่อขับรถเข้าใกล้บ้านในระยะ 5–15 เมตร (ปรับแต่งได้ตามความเร็วและหน้างาน) ประตูจะเริ่มเลื่อนเปิดต้อนรับทันทีโดยที่ผู้ขับขี่ไม่ต้องละมือจากพวงมาลัย
* **ห้องโดยสารส่งเสียงยืนยัน:** ตัวแท็กในรถจะส่งเสียงปี๊บสั้น 1 ครั้งเพื่อยืนยันว่า *"ประตูกำลังเปิดให้คุณแล้ว"*
* **ระบบกันเปิดซ้ำอัจฉริยะ (Baseline Suppression Engine):** เมื่อจอดรถดับเครื่องในบ้าน ตัวกล่องจะบันทึกว่ารถคันนี้จอดอยู่ในบ้านแล้ว และจะไม่ส่งคำสั่งเปิดประตูซ้ำอีกเด็ดขาด จนกว่ารถจะถูกขับออกไปนอกบ้านจริงๆ

### 3.2 รีโมท 4 ปุ่มแยกบทบาทอิสระ (4-Button Smart Remote)
แก้ปัญหาบ้านที่มีคนส่งของ, ช่างมาต่อเติม, หรือจัดงานปาร์ตี้ ด้วยการจัดสรรหน้าที่ของปุ่มอย่างสมบูรณ์แบบ:
* 🟢 **ปุ่ม A (โหมด Auto):** กดเปิดประตู ขับรถเข้าบ้าน และเมื่อรถพ้นลำแสงเซ็นเซอร์กันหนีบ ประตูจะนับถอยหลังปิดตามหลังให้อัตโนมัติ (Safety Auto-Close)
* 🟡 **ปุ่ม B (โหมดเปิดค้าง / Hold Open):** กดเปิดเพื่อรับรถส่งของหรือเปิดทิ้งไว้ ประตูจะเปิดค้างไว้ถาวร **แม้รถส่งของจะขับผ่านเซ็นเซอร์กี่สิบรอบ ประตูก็จะไม่ปิดเองเด็ดขาด** ช่วยให้ยกของสะดวกและปลอดภัย 100%
* 🔴 **ปุ่ม C (โหมดสั่งปิด & คืนสถานะ / Close):** เมื่อรถส่งของเสร็จงาน กดปุ่มนี้เพียงครั้งเดียว ประตูจะสั่งเลื่อนปิดทันที และ **คืนค่าระบบกลับเข้าสู่โหมดออโต้ปกติโดยอัตโนมัติ**
* ⚪ **ปุ่ม D (โหมดหยุดฉุกเฉิน / Stop):** สั่งหยุดการเคลื่อนที่ของประตูทันทีในตำแหน่งปัจจุบัน และค้างไว้จนกว่าจะมีคำสั่งใหม่

### 3.3 ระบบเซ็นเซอร์กันหนีบ 2 มิติ (Dual-Authority Safety Sensor)
* **ขณะประตูกำลังเลื่อนปิด:** หากมีเด็ก, สัตว์เลี้ยง, หรือสิ่งกีดขวางตัดลำแสงอินฟาเรด ระบบจะตัดการทำงานและสั่งถอยกลับ (SafeAbort) ทันทีเพื่อความปลอดภัยสูงสุด
* **ขณะเปิดค้างด้วยโหมดมือ:** เซ็นเซอร์จะทำหน้าที่ปกป้องความปลอดภัย แต่จะไม่สั่งปิดประตูเองตามอำเภอใจ

## 🛠️ 4. สถาปัตยกรรมเชิงวิศวกรรมสำหรับช่างและผู้ผลิต (Engineering & Architecture)

```
[ ESP-NOW Car Tag ] ──(2.4GHz Direct)──┐
                                       ▼
[ RF 433MHz Remote ] ─(433MHz OOK)───➔ [ AutoDoor-RF2 (ESP32-C3) ] ──(Dry Contact)──➔ [ Motor Control Board ]
                                       ▲              │                                     │
[ Smart Phone / PC ] ──(Wi-Fi WebUI)───┘              └──(Dual IR Safety Beam Input)───────┘
```

### 4.1 ข้อมูลสเปกฮาร์ดแวร์และอินเทอร์เฟซ (Hardware Specifications & Pinout)
* **Microcontroller Unit (MCU):** ESP32-C3 RISC-V 32-bit Single-Core Processor @ 160MHz
* **Flash Memory & ตารางพาร์ติชัน (Dual-OTA Architecture):** 4MB SPI Flash
  * `nvs`: 128 KB (จัดเก็บค่าคอนฟิกและรายการ Tag ได้สูงสุด 256 รายการ พร้อมสถาปัตยกรรม Zero-Latency Flat Hash Table ค้นหาเร็วสูงสุดระดับฮาร์ดแวร์ O(1))
  * `otadata`: 8 KB (สลับการบูตระหว่างสองเฟิร์มแวร์)
  * `app0` & `app1`: 1.81 MB ต่อช่อง (1,900,544 bytes) รองรับ Seamless OTA อัปเดตข้ามเวอร์ชันปลอดภัย
  * `spiffs` / LittleFS: 192 KB (จัดเก็บ WebUI และประวัติย้อนหลัง 180 วัน)
* **ผังขาอินเทอร์เฟซฮาร์ดแวร์ (Hardware Pinout Mapping):**
  * `GPIO 6`: คำสั่งเปิดประตู (OPEN Relay Pulse 500ms)
  * `GPIO 7`: คำสั่งปิดประตู (CLOSE Relay Pulse 500ms / 800ms)
  * `GPIO 6+7`: คำสั่งหยุดฉุกเฉิน (STOP Relay Pulse 1,200ms ยิงพร้อมกันผ่านฮาร์ดแวร์รีจิสเตอร์ `GPIO_OUT_W1TS_REG`)
  * `GPIO 9`: ปุ่ม BOOT หลัก (กดสั้น = Manual E-Stop / กดค้าง 5 วินาที = Safe Mode โหมดกู้คืนฉุกเฉิน)
  * `GPIO 2`: เซ็นเซอร์กันหนีบอินฟราเรด (Safety Infrared Beam - รองรับทั้ง NO/NC)
  * `GPIO 3`: เซ็นเซอร์แม่เหล็กภายนอกตรวจจับประตูปิดสนิท (External Magnetic Reed Switch)
  * `GPIO 0`: สัญญาณข้อมูลภาครับคลื่นวิทยุ 433.92MHz (RF433 RX Data)
* **RF 433MHz Receiver:** SYN480R High Sensitivity ASK/OOK Receiver IC พร้อมระบบ Hardware RC Filter ป้องกันสัญญาณรบกวนทางไฟฟ้าจากแปรงถ่านมอเตอร์
* **Wi-Fi & ESP-NOW Connectivity:** 802.11 b/g/n (2.4GHz) กำลังส่งมาตรฐาน 18.0 dBm ปรับตั้งค่าผ่าน Config กลาง `kWifiTxPowerDbm`
* **ระบบเครือข่ายอัจฉริยะ (Network Resiliency):**
  * สแกนและเปลี่ยน Wi-Fi ได้ทันทีในโหมดปกติ ไม่ต้องเข้า Safe Mode
  * **Auto-DHCP เมื่อเปลี่ยน SSID:** ปลด Fix IP อัตโนมัติเมื่อต่อ Wi-Fi ใหม่ ป้องกันปัญหา Subnet ไม่ตรง
  * **DHCP Fallback Safety Net:** สลับกลับมารับ DHCP ให้อัตโนมัติหลังเชื่อมต่อ Fix IP ไม่สำเร็จเกิน 30 วินาที
  * **Safe Mode Recovery:** เปิด Open AP แบบไม่มีรหัสผ่าน บังคับใช้ DHCP พร้อมปุ่มกู้คืนและรีสตาร์ทกลับโหมดปกติในคลิกเดียว
* **Output Relay Interface:** Dry Contact Isolation สั่งงานผ่านขั้วสวิตช์ภายนอกของมอเตอร์ได้ทุกยี่ห้อ (Zero Voltage Feedback)
* **Power Supply:** รองรับ DC Input 9V–28V (ดึงไฟเลี้ยง AUX 12V/24V จากบอร์ดมอเตอร์ได้โดยตรง) หรือหม้อแปลงแยก DC 12V 1A

### 4.2 สถาปัตยกรรมซอฟต์แวร์ 5 เลเยอร์ (5-Layer Architecture)
1. **Layer 1: Sensor & Input Processing:** กรองสัญญาณ Debounce ของเซ็นเซอร์อินฟาเรดและแม่เหล็กด้วย Multi-sample Filtering
2. **Layer 2: Tag & RF Trigger Evaluation:** ตรวจสอบสิทธิ์ RF Remote / ESP-NOW Tag พร้อมระบบกรอง Suppression ป้องกันการเปิดซ้ำ
3. **Layer 3: Auto-Close Priority Decision Engine:**
   - *Priority 1 (สูงสุด):* ปิดตามหลังเมื่อรถพ้นเซ็นเซอร์กันหนีบ (`gSafetyCloseAtMs`)
   - *Priority 2:* ปิดตามหลังเมื่อแท็กหลุดระยะตรวจจับ (`gPendingCloseAtMs`)
   - *Priority 3:* ปิดสำรองฉุกเฉิน (Fallback Failsafe Timer)
4. **Layer 4: Directional Reversal Deadband Actuator:**
   - เมื่อมีการสั่งสลับทิศทาง (เช่น กำลังเปิดแล้วสั่งปิด หรือกำลังปิดแล้วสั่งเปิด)
   - ระบบจะส่งสัญญาณ **STOP Pulse (GPIO 6+7 = HIGH 1200ms)** ผ่าน Register ระดับฮาร์ดแวร์ `GPIO_OUT_W1TS_REG` พร้อมกัน
   - หน่วงเวลาพักระบบกลไก **Deadband 1200ms (รวมกระบวนการ 2.4 วินาที)** เพื่อหยุดแรงเฉื่อยของมอเตอร์ ก่อนยิงพัลส์ทิศทางใหม่ (800ms)
5. **Layer 5: Transition & Auto-Retry Schedulers:** นับเวลาการเดินทางของประตู และระบบยิงพัลส์ปิดซ้ำ (Double Close / Auto-Retry Close) เมื่อตรวจพบว่าประตูปิดไม่สนิท

### 4.3 แผนผังการต่อสายเข้ากับบอร์ดมอเตอร์ยอดนิยม (Wiring Topology)

| ช่องต่อบนกล่อง AutoDoor-RF2 | ประเภทหน้าสัมผัส | ต่อเข้าขั้วของบอร์ดมอเตอร์ประตู (BSM / DEA / Albano / DC) |
| :--- | :--- | :--- |
| **POWER (+ / -)** | ไฟเลี้ยง DC 9-24V | ช่องไฟออก `+12V / +24V` และ `GND` ของบอร์ดมอเตอร์ |
| **OPEN** | Dry Contact (Normally Open) | ช่องสวิตช์เปิดภายนอก (`OPEN` หรือ `OP`) |
| **CLOSE** | Dry Contact (Normally Open) | ช่องสวิตช์ปิดภายนอก (`CLOSE` หรือ `CL`) |
| **STOP** | Dry Contact (Normally Open) | ช่องสวิตช์หยุดภายนอก (`STOP` หรือ `ST`) |
| **COM** | Dry Contact Common | ช่องสายร่วม (`COM` หรือ `GND`) ของสวิตช์คำสั่ง |
| **IR SENSOR (IN / GND)** | Digital Input (Optocoupler) | ต่อขนานกับขั้วหน้าสัมผัสของเซ็นเซอร์กันหนีบ (`IR / PHOTO / NC`) |

## 📢 5. คู่มือการตลาดสำหรับทีม Marketing, Content Creators & AI

### 5.1 กลุ่มลูกค้าเป้าหมาย (Customer Personas)

## ❓ 6. คำถามที่พบบ่อยสำหรับผู้ซื้อและช่าง (Commercial FAQ)

**Q: ประตูรั้วเดิมที่มีอยู่แล้ว ต้องเปลี่ยนมอเตอร์ใหม่หรือไม่?**
* **A:** ไม่ต้องเปลี่ยนครับ! AutoDoor-RF2 ออกแบบมาให้เป็นระบบ Add-on สั่งงานผ่านขั้ว Dry Contact ซึ่งเป็นมาตรฐานสากล สามารถต่อพ่วงเข้ากับมอเตอร์ประตูบานเลื่อนและบานสวิงได้ทุกยี่ห้อในท้องตลาด

**Q: ถ้าที่บ้านมีรถยนต์หลายคัน หรือเป็นอพาร์ตเมนต์/คอนโด/ออฟฟิศ รองรับรีโมทและแท็กได้กี่ตัว?**
* **A:** รองรับได้สูงสุดถึง **256 Tag** เลยครับ! (ผสมผสานได้ทั้ง ESP-NOW Car Tag ติดรถยนต์ และรีโมทไร้สาย RF 433MHz) มาพร้อมสถาปัตยกรรมค้นหาความเร็วสูง **Zero-Latency Flat Hash Table (O(1) ใน ~15–35 นาโนวินาที)** ไม่ว่าจะบันทึก 1 ตัวหรือ 256 ตัว เมื่อกดรีโมทหรือรถขับเข้ามา ประตูจะตอบสนองทันทีโดยไม่มีการหน่วงช้า และแต่ละคันสามารถตั้งค่าระยะความไว (RSSI Sensitivity), กำหนดเวลาเข้าบ้าน (Active Hours) และเวลาหน่วงปิดแยกอิสระจากกันได้บนหน้าเว็บครับ

**Q: ถ้ามีรถจอดอยู่ในบ้าน ประตูจะเผลอเปิดเองหรือไม่?**
* **A:** ไม่เปิดแน่นอนครับ ระบบมีกลไก **Baseline Active Suppression** เมื่อรถคันใดจอดดับเครื่องอยู่ในบ้านขณะประตูปิด ระบบจะจดจำและบล็อกสัญญาณการเปิดซ้ำไว้ จนกว่ารถคันนั้นจะขับออกจากบ้านจริงๆ

**Q: หากในอนาคตมีฟังก์ชั่นใหม่ ต้องแกะกล่องมาลงโปรแกรมใหม่หรือไม่?**
* **A:** ไม่ต้องแกะกล่องเลยครับ ตัวกล่องมีระบบ **Wireless Web OTA** สามารถเข้าหน้าเว็บผ่านมือถือ แล้วกดอัปโหลดไฟล์เฟิร์มแวร์ใหม่ผ่าน Wi-Fi ได้ทันทีใน 30 วินาที
