# 🔧 AutoDoor-RF2: คู่มือการติดตั้งและการต่อสายหน้างานสำหรับช่างมืออาชีพ
*(Professional Installer & Contractor Technical Wiring Manual)*

เอกสารนี้จัดทำขึ้นสำหรับช่างติดตั้งประตูรั้วอัตโนมัติ ผู้รับเหมางานประตู และช่างเทคนิคไฟฟ้า เพื่อใช้เป็นมาตรฐานในการติดตั้ง เดินสายสัญญาณ ปรับแต่งค่า และตรวจสอบความพร้อมในการส่งมอบงานกล่องควบคุม **AutoDoor-RF2**

---

## 📐 1. ข้อมูลจำเพาะทางไฟฟ้าและฮาร์ดแวร์ (Technical Specifications)

* **แรงดันไฟเลี้ยงขาเข้า (Power Input):** DC 9V – 28V (ขั้วต่อมีวงจรป้องกันไฟย้อนกลับ Reverse Polarity Protection)
  * *คำแนะนำ:* สามารถดึงไฟเลี้ยง AUX 12V หรือ 24V จากบอร์ดควบคุมมอเตอร์ประตูได้โดยตรง หรือใช้หม้อแปลงแยก DC 12V 1A
* **อินเทอร์เฟซคำสั่งมอเตอร์ (Relay Outputs):** Dry Contact Isolated Outputs (หน้าสัมผัสอิสระ ไม่มีแรงดันไฟฟ้ารั่วไหลสู่บอร์ดมอเตอร์)
  * รองรับกระแสสูงสุด: 3A @ 30VDC / 250VAC
* **อินเทอร์เฟซเซ็นเซอร์กันหนีบ (IR Safety Input):** รองรับสัญญาณ Digital Input (Optocoupler Isolation) ขนานได้ทั้งแบบ **Normally Open (NO)** และ **Normally Closed (NC)**
* **ภาครับคลื่นวิทยุ (RF 433.92MHz):** SYN480R High Sensitivity Receiver IC พร้อมวงจร Hardware RC Filter ป้องกันสัญญาณรบกวนแม่เหล็กไฟฟ้าจากประกายไฟของแปรงถ่านมอเตอร์
* **Wi-Fi & ESP-NOW:** ความถี่ 2.4GHz เสาอากาศ PCB ภายใน กำลังส่งมาตรฐาน 18.0 dBm
* **ปุ่มฟังก์ชั่นฮาร์ดแวร์บนบอร์ด (BOOT Button / GPIO 9):**
  * *กดสั้น 1 ครั้ง:* สั่งหยุดฉุกเฉิน (Manual E-Stop)
  * *กดค้าง 5 วินาที:* เข้าสู่โหมดกู้คืนฉุกเฉิน (Hardware Safe Mode)

## 🔌 2. ผังขาและการต่อสายเข้ากับบอร์ดมอเตอร์ (Wiring Topology)

```
┌─────────────────────────────────────────────────────────────┐
│                    AutoDoor-RF2 Controller                  │
│                                                             │
│   [POWER]       [OUTPUT RELAYS]            [SENSORS]        │
│   [+12V] [GND]   [OPEN] [CLOSE] [STOP] [COM]   [IR_IN] [IR_GND]  │
└─────┬──────┬───────┬──────┬──────┬──────┬─────────┬───────┬─────┘
      │      │       │      │      │      │         │       │
      ▼      ▼       ▼      ▼      ▼      ▼         ▼       ▼
┌─────────────────────────────────────────────────────────────┐
│              บอร์ดควบคุมมอเตอร์ประตูรั้ว (Motor Board)           │
│  [+12V/24V] [GND]  [OPEN] [CLOSE] [STOP] [COM]   [PHOTO/IR] [GND]   │
└─────────────────────────────────────────────────────────────┘
```

### 2.1 ตารางเชื่อมต่อสัญญาณมาตรฐาน (BSM, DEA, Albano, DC/AC Motors)

| ขั้วต่อบน AutoDoor-RF2 | ชนิดสัญญาณ | จุดเชื่อมต่อบนบอร์ดมอเตอร์ | หน้าที่การทำงาน |
| :--- | :--- | :--- | :--- |
| **POWER (+)** | DC Input (+) | ขั้วไฟออก `+12V` หรือ `+24V` (AUX) | ไฟเลี้ยงกล่องควบคุม |
| **POWER (-)** | DC Input (-) | ขั้ว `GND` หรือ `-` (AUX) | กราวด์ไฟเลี้ยง |
| **OPEN** | Dry Contact NO | ขั้วสวิตช์เปิด `OPEN` หรือ `OP` | สั่งเปิดประตู (พัลส์ 500ms) |
| **CLOSE** | Dry Contact NO | ขั้วสวิตช์ปิด `CLOSE` หรือ `CL` | สั่งปิดประตู (พัลส์ 500ms / 800ms) |
| **STOP** | Dry Contact NO | ขั้วสวิตช์หยุด `STOP` หรือ `ST` | สั่งหยุดมอเตอร์ (พัลส์ 1,200ms) |
| **COM** | Signal Common | ขั้วร่วม `COM` หรือ `GND` ของสวิตช์ | สัญญาณคอมมอนของคำสั่ง |
| **IR SENSOR (IN)** | Digital In (+) | ขั้วสัญญาณเซ็นเซอร์ `IR` / `PHOTO` / `NC` | รับรู้สถานะลำแสงกันหนีบ |
| **IR SENSOR (GND)**| Signal GND | ขั้วกราวด์เซ็นเซอร์ `GND` หรือ `COM` | กราวด์สัญญาณเซ็นเซอร์ |

> ⚠️ **ข้อควรระวังสำหรับบอร์ดที่มีพอร์ตสั่งงานปุ่มเดียว (Single-Button / Toggle Only):**
> หากบอร์ดมอเตอร์ของลูกค้ามีเฉพาะช่อง `STEP` หรือ `CYCLE` (ไม่มีช่องแยก OPEN/CLOSE):
> * ต่อช่อง `OPEN` ของ AutoDoor-RF2 เข้ากับช่อง `STEP` ของบอร์ดมอเตอร์
> * เข้าหน้า Web Dashboard เมนู **"ตั้งค่ามอเตอร์"** แล้วเลือกโหมดเป็น **"สวิตช์สเต็ปปุ่มเดียว (Single Button Toggle)"**

## 🛡️ 3. เจาะลึกกลไกถนอมเกียร์มอเตอร์: Reversal Deadband 2.4 วินาที

ช่างติดตั้งมักพบปัญหากล่อง Wi-Fi ทั่วไปสั่งกลับทิศทางมอเตอร์ทันที ทำให้เฟืองรูดหรือมอเตอร์ไหม้ AutoDoor-RF2 ได้รับการออกแบบเพื่อแก้ปัญหานี้โดยเฉพาะ:

```
[ มีคำสั่งกลับทิศทาง ] 
         │
         ▼
[ เฟสที่ 1: สั่ง STOP Pulse ทันที ] ➔ ยิง GPIO 6+7 = HIGH นาน 1,200 ms ผ่าน Register ฮาร์ดแวร์
         │
         ▼
[ เฟสที่ 2: หน่วงเวลาพักระบบกลไก (Deadband) ] ➔ พักระบบเกียร์นิ่ง 1,200 ms เพื่อหยุดแรงเฉื่อย
         │ (รวมเวลาพักกระบวนการกลไก 2.4 วินาที)
         ▼
[ เฟสที่ 3: ยิงพัลส์ทิศทางใหม่ ] ➔ ยิงพัลส์ OPEN หรือ CLOSE (800 ms) มอเตอร์เริ่มหมุนอย่างนุ่มนวล
```

* **จุดขายที่ช่างสามารถบอกลูกค้าได้:** "กล่องนี้จะไม่สั่งมอเตอร์กระชากเกียร์กลับลำเด็ดขาด มีระบบเบรกไฟฟ้าและพักเกียร์ 2.4 วินาที ยืดอายุการใช้งานมอเตอร์ของลูกค้าได้อย่างยาวนาน"

## 📋 4. ขั้นตอนการทดสอบหน้างาน (5-Step Commissioning Checklist)

เมื่อเดินสายเสร็จสิ้น ให้ปฏิบัติตามเช็กลิสต์ 5 ขั้นตอนต่อไปนี้ก่อนส่งมอบงาน:

- [ ] **ขั้นตอนที่ 1 (ตรวจสอบไฟเลี้ยง):** วัดแรงดันไฟเลี้ยงที่ขั้ว POWER ต้องอยู่ระหว่าง DC 9V–28V ไฟ LED สถานะสีน้ำเงินบนบอร์ดติดสว่าง
- [ ] **ขั้นตอนที่ 2 (ทดสอบทิศทางมอเตอร์):** กดปุ่มเปิด-ปิดบนหน้า Web Dashboard หรือรีโมท สังเกตว่าประตูเปิดและปิดตรงตามคำสั่ง (หากสลับทิศ ให้กดสลับสวิตช์ **"กลับทิศทางมอเตอร์"** ในหน้าตั้งค่า)
- [ ] **ขั้นตอนที่ 3 (ทดสอบเซ็นเซอร์กันหนีบ IR Beam):**
  - ขณะประตูกำลังเลื่อนปิด ให้ใช้มือหรือแผ่นกระดาษบังลำแสงเซ็นเซอร์
  - ประตูต้อง **หยุดและถอยกลับเปิดทันที (Safe Abort)**
  - เมื่อนำมือออก ประตูต้องนับถอยหลังตามที่ตั้งค่าไว้ (เช่น 3-5 วินาที) แล้วปิดตามหลังอัตโนมัติ
- [ ] **ขั้นตอนที่ 4 (ทดสอบโหมดเปิดค้างส่งของ / ปุ่ม B บนรีโมท):**
  - กดปุ่ม B ประตูเปิดค้าง
  - ให้คนเดินตัดผ่านเซ็นเซอร์กันหนีบไป-มา 3 ครั้ง ประตูต้อง **นิ่งสนิท ไม่ปิดตามหลัง**
  - กดปุ่ม C ประตูต้องปิดลงทันทีและคืนค่าเข้าสู่โหมดออโต้ปกติ
- [ ] **ขั้นตอนที่ 5 (ทดสอบแท็กติดรถยนต์ ESP-NOW):**
  - เสียบแท็กในรถยนต์ ขับรถออกจากบ้านไป 30 เมตร แล้วขับกลับเข้ามา
  - ประตูต้องเริ่มเปิดเมื่อรถเข้าสู่ระยะ 5–15 เมตร พร้อมได้ยินเสียงปี๊บในรถ 1 ครั้ง
  - ขับรถเข้าจอด ประตูต้องปิดตามหลัง และมีเสียงปี๊บยืนยัน 2 ครั้งเมื่อประตูปิดสนิท

## 🚨 5. โหมดกู้คืนฉุกเฉินระดับฮาร์ดแวร์ (Hardware Safe Mode)

หากเกิดปัญหาหน้างาน เช่น เจ้าของบ้านเปลี่ยนเราเตอร์ Wi-Fi ใหม่ หรือลืมรหัสผ่าน Wi-Fi จนไม่สามารถเข้าหน้าเว็บได้:

1. **วิธีกดเข้า Safe Mode:** กดปุ่ม **BOOT (GPIO 9)** บนบอร์ดค้างไว้ **5 วินาที** แล้วปล่อย
2. **การทำงานของ Safe Mode:**
   * บอร์ดจะตัดการทำงานของระบบอัตโนมัติทั้งหมดเพื่อความปลอดภัย
   * บอร์ดจะปล่อยสัญญาณ Wi-Fi Hotspot ชื่อ `AutoLink-RECOVERY` (ไม่มีรหัสผ่าน)
   * บอร์ดจะบังคับใช้งานระบบรับ IP อัตโนมัติ (DHCP)
3. **การกู้คืน:**
   * เชื่อมต่อ Wi-Fi `AutoLink-RECOVERY` ด้วยมือถือ
   * เปิดเบราว์เซอร์ไปที่ `http://192.168.4.1`
   * เลือกเมนูสแกนและใส่รหัสผ่าน Wi-Fi บ้านใหม่
   * กดปุ่ม **"รีสตาร์ทกลับสู่โหมดปกติ (Normal Mode)"**

## 🛠️ 6. ตารางแก้ไขปัญหาหน้างาน (Field Troubleshooting)

| อาการที่พบ | สาเหตุที่เป็นไปได้ | แนวทางแก้ไขสำหรับช่าง |
| :--- | :--- | :--- |
| **กดเปิดแล้วประตูกลับเลื่อนปิด** | การต่อสายสลับขั้ว OPEN/CLOSE หรือการตั้งค่าทิศทางมอเตอร์กลับด้าน | สลับสายขั้ว OPEN กับ CLOSE หรือเปิดสวิตช์ **"กลับทิศทางมอเตอร์"** ในหน้าเว็บ |
| **ประตูปิดตามหลังทันที ทั้งที่ไม่ได้ตั้งให้ปิดเร็ว** | หน้าสัมผัสเซ็นเซอร์กันหนีบตั้งค่าสลับแบบ (NO/NC) | เข้าหน้าตั้งค่าระบบ แล้วสลับตัวเลือก **"ประเภทเซ็นเซอร์กันหนีบ (Invert IR)"** จาก NO เป็น NC หรือ NC เป็น NO |
| **ขับรถเข้าใกล้บ้านแล้วประตูไม่เปิด** | 1. ค่าความไวสัญญาณ (RSSI) ตั้งไว้แคบเกินไป<br>2. Tag อยู่ในสถานะถูกบล็อกเพราะเพิ่งจอด | 1. ปรับแถบเลื่อนความไวไปทางซ้ายให้กว้างขึ้น (เช่น `-105 dBm`)<br>2. ตรวจสอบว่ารถได้ขับออกไปพ้นระยะจริงๆ ก่อนกลับเข้ามา |
| **รีโมท 433MHz สั่งงานได้ระยะสั้น หรือสั่งได้บ้างไม่ได้บ้าง** | สัญญาณรบกวนจากมอเตอร์ หรือเสาอากาศขดลวดถูกกดทับ | คลี่สายอากาศทองแดงของภาครับ RF ให้ยืดตรง และติดตั้งกล่องให้ห่างจากตัวถังมอเตอร์อย่างน้อย 10–20 ซม. |
