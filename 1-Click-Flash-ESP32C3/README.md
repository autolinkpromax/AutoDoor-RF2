# AutoDoor ESP32-C3 1-Click Firmware Flasher

โปรแกรมสำหรับแฟลชเฟิร์มแวร์ **AutoDoor ESP32-C3** ผ่านสาย USB แบบ 1-Click มีระบบเลือก COM Port อัตโนมัติ พร้อมตรวจจับการเสียบสาย USB แบบเรียลไทม์ และแถบแสดงความคืบหน้า (Progress Bar) 0% - 100%

---

## 🚀 วิธีเปิดโปรแกรมและใช้งานแบบ 1-Click

### วิธีเปิดโปรแกรม:
* **เปิดจากโฟลเดอร์หลักของโปรเจกต์:** ดับเบิลคลิกที่ไฟล์ **`One-Click-Flash-ESP32C3.bat`**
* **เปิดจากโฟลเดอร์นี้:** ดับเบิลคลิกที่ไฟล์ **`1-CLICK-GUI.bat`**
* **สร้างไอคอนบนหน้าจอคอมพิวเตอร์:** ดับเบิลคลิกที่ไฟล์ **`Create-Desktop-Shortcut.bat`** (ที่โฟลเดอร์หลัก) เพื่อสร้าง Shortcut บน Desktop

---

### ขั้นตอนการแฟลชลงบอร์ด (ง่ายมากใน 3 สเต็ป):
1. **เสียบสาย USB** ระหว่างคอมพิวเตอร์กับบอร์ด ESP32-C3
2. เปิดโปรแกรมขึ้นมา:
   - ระบบจะตรวจจับและเลือก **COM Port ของ ESP32-C3 ให้อัตโนมัติ**
   - แถบสถานะด้านบนจะแสดงเป็นสีเขียว 🟢 **เชื่อมต่อแล้ว (COMxx)**
   - หากยังไม่ได้เสียบสาย USB แล้วเพิ่งเสียบ ระบบจะตรวจพบและเลือกพอร์ตให้เองภายใน 1.5 วินาที
3. กดปุ่ม **`⚡ ONE CLICK FLASH (อัพโหลดลงบอร์ด)`**
   - แถบ Progress Bar จะวิ่งบอกสถานะเรียลไทม์ (0% ➔ 100%)
   - เมื่อเสร็จสิ้นจะมีหน้าต่างแจ้งเตือน บอร์ดจะรีบูตและเริ่มทำงานทันที!

## 📋 รายละเอียดโครงสร้าง Partition Table (ESP32-C3 4MB 2x OTA)

ระบบนี้ใช้ไฟล์พาร์ติชัน `partitions_two_ota.csv` ซึ่งออกแบบมาเป็นพิเศษเพื่อรองรับการเก็บข้อมูล Tag จำนวนมาก:

| ชื่อ Partition | ประเภท | Offset (Hex) | ขนาด | การใช้งาน |
| :--- | :--- | :--- | :--- | :--- |
| **bootloader** | Bootloader | `0x0000` | ~19.5 KB | ESP32-C3 ROM Bootloader |
| **partitions** | Partition Table | `0x8000` | 3 KB | ตารางระบุพาร์ติชันทั้งหมดใน Flash |
| **nvs** | NVS Data | `0x9000` | 128 KB (`0x20000`) | เก็บข้อมูลแท็ก (Tags), WiFi, รหัสผ่าน Web, Webhook |
| **otadata** (`boot_app0`) | OTA Data | `0x29000` | 8 KB (`0x2000`) | จัดเก็บสถานะการเลือกบูตระหว่าง `app0` กับ `app1` |
| **app0** (`firmware`) | App (OTA 0) | `0x30000` | 1.81 MB (`0x1D0000`) | ตัวโปรแกรมหลักช่องที่ 1 (เริ่มต้นบูตที่นี่) |
| **app1** | App (OTA 1) | `0x200000` | 1.81 MB (`0x1D0000`) | ตัวโปรแกรมช่องที่ 2 สำหรับสลับเมื่อทำ Online OTA |
| **spiffs** | SPIFFS Data | `0x3D0000` | 192 KB (`0x30000`) | พื้นที่จัดเก็บไฟล์ระบบ SPIFFS (สิ้นสุดที่ 4MB) |

> [!IMPORTANT]
> **ทำไม Offset ของ Firmware ต้องอยู่ที่ `0x30000` ไม่ใช่ `0x10000`?**
> เนื่องจากพาร์ติชัน `nvs` ถูกขยายเป็น 128 KB (เริ่มต้น `0x9000` สิ้นสุด `0x29000`) เพื่อรองรับข้อมูลแท็กและคอนฟิก ทำให้ `otadata` ถูกเลื่อนไปที่ `0x29000` และตำแหน่ง `app0` ต้องเลื่อนไปที่ `0x30000` เพื่อให้ตรงตามข้อกำหนด 64KB MMU alignment ของ ESP32
> หากแฟลชไปที่ `0x10000` จะทำให้ข้อมูลเขียนทับ NVS และชิปจะไม่สามารถบูตได้ โปรแกรมนี้ล็อกพิกัดที่ถูกต้องตามตารางพาร์ติชัน 100%

## 🛠️ การแก้ไขปัญหาเบื้องต้น (Troubleshooting)

1. **โปรแกรมขึ้นว่า "🔴 รอเสียบสาย USB":**
   * ตรวจสอบว่าสาย USB เป็นสายข้อมูล (Data Cable) ไม่ใช่สายชาร์จอย่างเดียว
   * ลองกดปุ่ม **🛠️ Device Manager** บนโปรแกรมเพื่อดูว่ามี Ports (COM & LPT) ขึ้นหรือไม่
2. **โปรแกรมค้างที่ `Connecting... ___...___` แล้วแจ้ง Timeout:**
   * **วิธีแก้ไข:** ให้กดปุ่ม **BOOT** บนบอร์ด ESP32-C3 ค้างไว้ ➔ จากนั้นกดปุ่ม **RESET (EN)** 1 ครั้ง ➔ แล้วปล่อยปุ่ม BOOT เพื่อบังคับให้บอร์ดเข้าโหมด Download Bootloader ➔ จากนั้นกดปุ่ม One Click Flash ใหม่อีกครั้ง
3. **แฟลชแล้วหลุดกลางคัน:**
   * เปลี่ยนความเร็ว Baud Rate เป็น `115200`
