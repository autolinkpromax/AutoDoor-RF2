# AutoDoor ESP32-C3 1-Click Firmware Flasher

เครื่องมือสำหรับแฟลชเฟิร์มแวร์ **AutoDoor ESP32-C3** แบบง่ายที่สุด (1-Click) ตรวจจับพอร์ต Serial อัตโนมัติ และตรวจสอบความถูกต้องของ Partition Table ให้ตรงตามสเปก 100%

---

## 🚀 วิธีใช้งานแบบ 1-Click

### วิธีที่ 1: แฟลชผ่านสาย USB (แนะนำ)
1. เสียบสาย USB ระหว่างคอมพิวเตอร์กับบอร์ด ESP32-C3
2. ดับเบิลคลิกที่ไฟล์ **`1-CLICK-FLASH.bat`**
3. โปรแกรมจะตรวจสอบ Partition Table, สแกนหาพอร์ต ESP32-C3 อัตโนมัติ และเริ่มแฟลชทันที (หรือกด Enter เพื่อยืนยัน)

### วิธีที่ 2: ใช้งานผ่านหน้าต่างกราฟิก (GUI)
1. ดับเบิลคลิกที่ไฟล์ **`1-CLICK-GUI.bat`**
2. เลือกพอร์ต COM ที่ตรวจพบ (หรือกดปุ่ม 🔄 เพื่อสแกนใหม่)
3. กดปุ่ม **`⚡ 1-Click Flash (USB Cable)`**

### วิธีที่ 3: อัปเดตไร้สายผ่าน WiFi OTA (ไม่ต้องต่อสาย)
1. เชื่อมต่อ WiFi วงเดียวกับ AutoDoor (`192.168.1.11`)
2. ดับเบิลคลิกที่ไฟล์ **`OTA-UPDATE.bat`**
3. โปรแกรมจะส่งไฟล์เฟิร์มแวร์ผ่าน HTTP OTA และรอจนกว่าบอร์ดจะบูตเสร็จ

## 📋 รายละเอียดโครงสร้าง Partition Table (ESP32-C3 4MB 2x OTA)

ระบบนี้ใช้ไฟล์พาร์ติชัน `partitions_two_ota.csv` ซึ่งออกแบบมาเป็นพิเศษเพื่อรองรับการเก็บข้อมูล Tag จำนวนมาก:

| ชื่อ Partition | ประเภท | Offset (Hex) | ขนาด | การใช้งาน |
| :--- | :--- | :--- | :--- | :--- |
| **bootloader** | Bootloader | `0x0000` | ~19.5 KB | ESP32-C3 ROM Bootloader |
| **partitions** | Partition Table | `0x8000` | 3 KB | ตารางระบุพาร์ติชันทั้งหมดใน Flash |
| **nvs** | NVS Data | `0x9000` | 128 KB (`0x20000`) | เก็บข้อมูลแท็ก (Tags), WiFi, รหัสผ่าน Web, Webhook |
| **otadata** (`boot_app0`) | OTA Data | `0x29000` | 8 KB (`0x2000`) | จัดเก็บสถานะการเลือกบูตระหว่าง `app0` กับ `app1` |
| **app0** (`firmware`) | App (OTA 0) | `0x30000` | 1.81 MB (`0x1D0000`) | ตัวโปรแกรมหลักช่องที่ 1 (เริ่มต้นบูตที่นี่) |
| **app1** | App (OTA 1) | `0x200000` | 1.81 MB (`0x1D0000`) | ตัวโปรแกรมช่องที่ 2 สำหรับสลับเมื่อทำ Online OTA |
| **spiffs** | SPIFFS Data | `0x3D0000` | 192 KB (`0x30000`) | พื้นที่จัดเก็บไฟล์ระบบ SPIFFS (สิ้นสุดที่ 4MB) |

> [!IMPORTANT]
> **ทำไม Offset ของ Firmware ต้องอยู่ที่ `0x30000` ไม่ใช่ `0x10000`?**
> เนื่องจากพาร์ติชัน `nvs` ถูกขยายเป็น 128 KB (เริ่มต้น `0x9000` สิ้นสุด `0x29000`) เพื่อรองรับข้อมูลแท็กและคอนฟิก ทำให้ `otadata` ถูกเลื่อนไปที่ `0x29000` และตำแหน่ง `app0` ต้องเลื่อนไปที่ `0x30000` เพื่อให้ตรงตามข้อกำหนด 64KB MMU alignment ของ ESP32
> หากแฟลชไปที่ `0x10000` จะทำให้ข้อมูลเขียนทับ NVS และชิปจะไม่สามารถบูตได้

## 📁 โครงสร้างไฟล์ในโฟลเดอร์นี้

```
1-Click-Flash-ESP32C3/
├── 1-CLICK-FLASH.bat      # ⚡ ดับเบิลคลิกเพื่อแฟลช USB แบบ 1-Click
├── 1-CLICK-GUI.bat        # 🖥️  ดับเบิลคลิกเพื่อเปิดหน้าต่างกราฟิก
├── OTA-UPDATE.bat         # 🌐 ดับเบิลคลิกเพื่ออัปเดตผ่าน WiFi OTA (192.168.1.11)
├── flasher.py             # ⚙️  สคริปต์หลัก ควบคุมการตรวจพอร์ต เช็คพาร์ติชัน และแฟลช
├── README.md              # 📖 คู่มือการใช้งานนี้
└── bin/                   # 📦 ไฟล์ไบนารีทั้งหมด
    ├── bootloader.bin     # ESP32-C3 Bootloader (Offset: 0x0000)
    ├── partitions.bin     # Partition Table (Offset: 0x8000)
    ├── boot_app0.bin      # OTA Boot Initializer (Offset: 0x29000)
    └── firmware.bin       # AutoDoor Release Firmware (Offset: 0x30000)
```

## 🛠️ การแก้ไขปัญหาเบื้องต้น (Troubleshooting)

1. **แฟลชไม่เข้า / หาพอร์ตไม่เจอ:**
   * ตรวจสอบว่าสาย USB เป็นสายข้อมูล (Data Cable) ไม่ใช่สายชาร์จอย่างเดียว
   * ตรวจสอบใน Device Manager ว่ามีพอร์ต เช่น "USB Serial Device" หรือ "CH340" ขึ้นหรือไม่
2. **โปรแกรมแจ้ง `Connecting... ___...___` แล้ว Timeout:**
   * ให้กดปุ่ม **BOOT** บนบอร์ด ESP32-C3 ค้างไว้ แล้วกดปุ่ม **RESET (EN)** 1 ครั้ง จากนั้นปล่อยปุ่ม BOOT เพื่อให้บอร์ดเข้าโหมด Download Bootloader แล้วกดแฟลชใหม่อีกครั้ง
3. **ต้องการปรับความเร็ว (Baud rate):**
   * สามารถรันผ่าน Command Line: `python flasher.py --flash --baud 115200` (สำหรับสายยาวหรือพอร์ตที่มีสัญญาณรบกวน)
