## 📑 สรุปเกณฑ์การผ่านการทดสอบ (Pass / Fail Criteria)
* **ผ่าน (Pass [ / ]):** ประตูตอบสนองตรงตามผลลัพธ์ที่คาดหวัง ไม่มีการหยุดค้าง ไม่กระตุก ไม่ส่งสัญญาณซ้ำซ้อน
* **ไม่ผ่าน (Fail [ X ]):** ประตูทำงานผิดจังหวะ ค้างเปิด ไม่ยอมปิด หรือเกิดอาการกระตุกรัว

| **TC-RF-06** | **(ทดสอบตั้งหน่วง 0 วินาที)**<br>ปิดทันทีที่พ้นลำแสง | 1. ตั้งค่าใน Tag: `หน่วงเวลาปิดหลังตรวจจับรถสำเร็จ = 0 วินาที`<br>2. กด RF Tag เปิด ➔ ขับผ่านลำแสงจนพ้น | • ทันทีที่ท้ายรถพ้นเส้นลำแสง ประตูต้องสั่งยิงพัลส์ `CLOSE` ปิดตามหลังทันที 0ms (ไม่รอเวลา) | [ ] Pass<br>[ ] Fail | |
| **TC-RF-07** | **(ทดสอบตั้งหน่วง 2-3 วินาที)**<br>จังหวะกระชับปลอดภัย | 1. ตั้งค่าใน Tag: `หน่วงเวลาปิดหลังตรวจจับรถสำเร็จ = 3 วินาที`<br>2. กด RF Tag เปิด ➔ ขับผ่านลำแสงจนพ้น | • ท้ายรถพ้นลำแสง ➔ นับถอยหลัง 3 วินาที ➔ ยิงพัลส์ `CLOSE` ปิดตามหลัง | [ ] Pass<br>[ ] Fail | |
